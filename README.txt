PASUPULA VARSHINI — PORTFOLIO WEBSITE

Files:
- index.html: Home page
- education.html: Education
- skills.html: Technical and professional skills
- projects.html: Projects
- experience.html: Internship experience
- certificates.html: Certifications
- achievements.html: Coding profiles and activities
- contact.html: Contact and social links
- style.css: Shared responsive styling and color theme
- script.js: Mobile navigation interaction

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a browser.
3. To publish with GitHub Pages, upload the contents of this folder to the root of a GitHub repository and enable Pages in repository Settings.

CUSTOMIZE
- Replace the initials avatar (PV) with a profile photo if desired.
- Check the email address and all profile links before publishing.
- Add certificate PDF files and update certificates.html if you want downloadable certificates.

CONTENT NOTE
Portfolio details were adapted from the résumé and profile links supplied in the conversation. No project-specific repository URL or certificate PDFs were present in the supplied files, so the project card links to the GitHub profile and certificate entries are informational.
